03 · Claude Playbook

Claude 활용 방법

별도 개발 없이 Claude의 기본 기능을 조합해 튜터앱을 완성합니다.

1

프로젝트 (튜터 지정)

언어별 전용 튜터 설정
사용 예시“일본어 튜터” 프로젝트에 “JLPT N4 수준, 틀린 표현 교정 후 한국어로 이유 설명” 등록
2

아티팩트 (웹 화면)

퀴즈·단어장 화면을 웹앱으로 제작
사용 예시“일본어 단어 퀴즈 웹 만들어줘” → 링크로 휴대폰에서 사용
3

음성 모드

말하기·듣기 회화 연습
사용 예시출퇴근길 모바일 앱에서 영어 회의 롤플레이
4

메모리

내 수준·약점 누적
사용 예시“조사 실수가 많다”를 기억해 다음 학습에 반영
5

Claude Code선택

정식 앱 개발·배포
사용 예시가족·동료와 공유할 때만 검토

05 · Result

실행결과: 일본어 단어 퀴즈

Claude 아티팩트 기능으로 ‘일본어 단어 퀴즈’ 웹을 제작, 휴대폰 홈 화면에 추가해 사용할 수 있습니다.

0개초급 (JLPT N5)
0개중급 (N4~N3, 업무·생활)
0문항1회 구성
0지선다문제 방식

구성 · 기능 · 화면

  • 구성초급(JLPT N5) 60개, 중급(N4~N3, 업무·생활 중심) 60개, 1회 10문항 4지선다
  • 기능뜻 맞히기·단어 맞히기, 후리가나 표시, 발음 듣기, 틀린 단어 자동 저장·복습
  • 화면 ①문제 풀이 – 답 선택 시 정답·읽기 즉시 표시
  • 화면 ②결과 – 점수·틀린 단어 정리, 틀린 단어만 재학습 가능
🔗 웹 바로가기 (단어 퀴즈 열기)

👉 오른쪽 화면은 바로 풀어볼 수 있는 체험용 데모입니다. 전체 화면 퀴즈(초급·중급 선택)는 웹 바로가기에서 열립니다.
